# Roots & Relics 🌿

**A modern e-commerce website for handcrafted home décor and lifestyle products.**

Roots & Relics is a frontend web project designed to showcase beautiful, handcrafted products inspired by traditional Indian artistry and contemporary home décor. The website provides a clean, elegant shopping experience for customers exploring unique décor pieces and gift items.

## ✨ Features

- **Elegant Homepage** — A modern, visually appealing landing page.
- **Product Listings** — Display handcrafted décor and lifestyle products.
- **Product Categories** — Browse products by category.
- **Search and Filtering** — Find products using search and category filters.
- **Shopping Cart** — Add products to the cart and update quantities.
- **Wishlist** — Save favourite products.
- **Responsive Design** — Designed to adapt to desktop and mobile screens.
- **Newsletter Section** — Includes a newsletter subscription interface.

## 🛍️ Product Categories

- Home Décor

- Diyas and Candle Holders

## 🚀 Getting Started

Follow these steps to run the project locally.

### Prerequisites

Make sure you have installed:

- [Node.js](https://nodejs.org/)
- npm (included with Node.js)
- [Git](https://git-scm.com/)

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/YOUR_USERNAME/roots-and-relics.git
```

**2. Navigate to the project folder**

```bash
cd roots-and-relics
```

If your React application is inside a `Frontend` folder, run `cd Frontend` as well.

**3. Install dependencies**

```bash
npm install
```

**4. Start the development server**

```bash
npm run dev
```

**5. Open the local website**

Open the URL displayed in your terminal, usually:

```text
http://localhost:5173/
```
